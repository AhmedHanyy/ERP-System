# SmartERP - AI-Powered Retail Management System

A high-performance ERP system designed for retail brands, featuring integrated Business Intelligence (BI), automated procurement, and predictive sales analytics.

## 🚀 Features
- **Operations Dashboard**: Real-time KPIs, sales performance tracking, and inventory status.
- **AI Analytics**: Demand forecasting, RFM customer segmentation, and Market Basket analysis.
- **Inventory & Orders**: Full lifecycle management from stock alerts to delivery tracking.
- **Supply Chain**: Procurement request workflows with supplier performance rating.
- **Premium UI**: Modern light theme with responsive charts and data-driven visualizations.

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Recharts, Lucide Icons.
- **Backend**: Python, Flask, SQLAlchemy.
- **Data Mining**: Scikit-learn, Pandas, Mlxtend (Apriori).
- **Database**: SQLite (Development) / swappable to PostgreSQL.

## 📦 Installation

### Backend
1. `cd backend`
2. `python -m venv venv`
3. `.\venv\Scripts\activate` (Windows)
4. `pip install -r requirements.txt`
5. `python run.py`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
